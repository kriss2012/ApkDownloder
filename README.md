# 🌌 Apex Deck (ApkDownloder)

[![Live Site](https://img.shields.io/badge/Live-Demo-00f2ff?style=for-the-badge&logo=netlify&logoColor=black)](https://androidappdown.netlify.app/)
[![Developer](https://img.shields.io/badge/Developer-kriss2012-7000ff?style=for-the-badge&logo=github)](https://github.com/kriss2012)

A futuristic, high-performance digital artifact gallery and APK downloader. Built with a cyberpunk aesthetic, featuring real-time 3D animations and a premium glassmorphism interface.

## ✨ Key Features

- **🌐 Futuristic 3D Environment**: Immersive background powered by `Three.js` and `React Three Fiber`.
- **💎 Premium Glassmorphism UI**: High-end visual design with blurred surfaces and neon accents.
- **🎬 Interactive Animations**: Smooth transitions and hover effects using `Framer Motion`.
- **📦 Digital Artifacts**: Curated list of APKs with detailed descriptions and direct download links.
- **📱 Fully Responsive**: Optimized for all devices, from desktop to mobile.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/) / [@react-three/fiber](https://github.com/pmndrs/react-three-fiber)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS with Cyberpunk-inspired tokens.

## 🚀 Getting Started

To run the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kriss2012/ApkDownloder.git
   ```

2. **Navigate to the website directory**:
   ```bash
   cd website
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```
